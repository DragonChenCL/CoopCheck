Flock size

Fort Collins City Code §4-117(b)(3): under 0.5 acre up to EIGHT chicken/duck HENS COMBINED

Read the full rule and exceptions

Fort Collins City Code §4-117(b)(3): under 0.5 acre up to EIGHT chicken/duck HENS COMBINED; 0.5–1 acre up to TWELVE; >1 acre six extra for every additional 0.5 acre (notice abutting owners if >12). Chapter 4 poultry licence and animal welfare standards still apply. Check precise acreage endpoints with City Animal Services.

Roosters

Fort Collins City Code §4-117(b)(2): ROOSTERS and DRAKES (male ducks) prohibited from ordinary residential chicken/duck keeping

Read the full rule and exceptions

Fort Collins City Code §4-117(b)(2): ROOSTERS and DRAKES (male ducks) prohibited from ordinary residential chicken/duck keeping; only hens. Other agricultural/zoning rights not inferred.

Permits and approvals

This field has conditions that need a closer look.

Read the full rule and exceptions

NOCO Humane, Fort Collins' contracted Animal Protection & Control agency, requires a one-time $30 chicken/duck COOP LICENSE and an enclosure inspection BEFORE licensing. Separate zoning, building and HOA permissions may apply.

Coop placement

This field has conditions that need a closer look.

Read the full rule and exceptions

Fort Collins City Code §4-117(b): poultry house and outdoor run at least FIFTEEN ft from ABUTTING PROPERTY LINE unless abutting owners provide WRITTEN CONSENT; house secured from predators overnight and adequate day enclosure required. No blanket coop-building permit waiver.
