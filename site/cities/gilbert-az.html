Questions to check before building

How many chickens can I keep here?

Gilbert's official Code Compliance FAQ says that on each lot up to 20,000 sq ft, up to 25 fowl and rodents combined are allowed under town code/Land Development Code provisions; the count is NOT a universal hen entitlement and must be reconciled with parcel zoning and Arizona's 2024 backyard-fowl preemption.

Are roosters allowed?

Gilbert Code Compliance FAQ does not establish a simple citywide rooster entitlement or prohibition; inspect Chapter 6 and Land Development Code §2.107 for the parcel and any current nuisance restrictions.

Do I need a permit?

Confirm Town Code §§6-126–127, Land Development Code §2.107, and parcel zoning with Gilbert Code Compliance.

Where can the coop be placed?

Coop siting and structure rules require parcel-level checks; no universal chicken-coop setback confirmed in the official FAQ.

Before buying birds or constructing a coop

Confirm that your address is inside the correct city jurisdiction; look up your parcel zoning; confirm flock-size and rooster restrictions, any poultry permit, neighboring-dwelling or property-line separation, accessory-structure/building permits, and HOA or deed restrictions.
