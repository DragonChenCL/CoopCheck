Backyard chicken laws in Corvallis, OR

Corvallis §5.03.050.020.06(7)(a) EXPRESSLY EXEMPTS domesticated fowl kept in pens/cages from the specific LIVESTOCK REGISTRATION obligation imposed on other livestock. This does NOT establish exemption from zoning review, animal nuisance rules or a construction/building permit for an actual coop.

Corvallis: registration is not the same as permission to build

The previously reviewed Corvallis livestock-registration provision describes an exception for domesticated fowl kept in pens or cages. That narrow exception should not be interpreted as an unlimited number of hens, permission to keep roosters, freedom from nuisance rules, or a chicken-coop building permit waiver. Those are separate questions governed by other city and state provisions.

If you are evaluating a Corvallis backyard, start by checking the address and residential zoning, then read the Municipal Code for animal control and nuisance standards. Check the Land Development Code and the accessory-structures guidance before locating a permanent coop. We have not established a universal chicken-specific setback from the registration section, so an automatically generated 10- or 20-foot buffer would be unsupported. The free lot planner is only a measurement sketch until those questions are answered.
