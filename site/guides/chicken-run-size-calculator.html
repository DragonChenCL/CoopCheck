Chicken run size calculator: how much outdoor space?

Free chicken run size calculator for 2–100 hens. Enter width and length, compare usable outdoor run area to a transparent space target, then plan a layout.

Calculate an outdoor run for your chickens

How big should the outdoor run be? CoopCheck uses a transparent illustrative target of 10 square feet of usable run per adult standard hen. The calculator checks your measured rectangle against that target, without counting the roofed sleeping coop as run space. It does not assume your municipality authorizes this flock.

Illustrative geometry only. Confirm build constraints separately.

The run target is an optional planning rule, not a universal minimum. Virginia Cooperative Extension lists 10 sq ft outside run per laying hen. Breed, confinement, enrichment and climate change what works.

Worked example: 6 hens

6 × 10 = 60 sq ft of usable outdoor run. Rectangles such as 6 × 10 ft, 5 × 12 ft or 4 × 15 ft all have the same area, but a very narrow enclosure can reduce practical movement, cleaning access and enrichment. A 4 × 6 ft sleeping coop, if used, must be counted and checked separately.

Entering a 6 × 10 ft run and 8 hens produces only 60 sq ft for an 80-sq-ft target, so the calculator shows a shortfall.

Checklist before building a chicken run

  1. Measure the usable rectangle, excluding permanent storage and inaccessible corners.
  2. Choose ground that drains and allows dust baths and shade, not standing water.
  3. Plan predator-resistant mesh, secure doors, roof protection and possible buried barrier.
  4. Read local rules for distance from property lines or neighboring residences; do not infer setbacks from the flock-size calculator.

Indoor coop vs. outdoor run

The sleeping coop provides sheltered interior floor, roosts and nesting spaces. The outdoor run is protected exercise space. A 24-sq-ft coop and 60-sq-ft run are two independent requirements for a six-hen illustration, not an 84-sq-ft sleeping area. For detailed indoor sizing, try the coop size calculator. For an actual city rule, start from the municipal policy directory.

The equal-area trap: compare shapes before cutting fence

Three hypothetical runs each provide 60 sq ft: 6 x 10 ft, 5 x 12 ft and 4 x 15 ft. Their perimeters are 32, 34 and 38 ft. The narrowest needs six extra linear feet of perimeter compared with the first, despite supplying the same ground area.

Mark the door, feeder, dry area and cleaning route on each outline. If a two-by-three-foot permanently inaccessible storage bay occupies the run, the 60-square-foot gross figure falls to 54. A cover or raised item does not automatically make all floor beneath it unusable.

Output to keep: usable ground, width at the narrowest working point, gate clearance and measured perimeter. Send the perimeter to the fencing tool instead of estimating mesh from floor area. The comparison is geometry, not a drainage or predator-resistance design.
