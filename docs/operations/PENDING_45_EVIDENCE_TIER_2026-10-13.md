It would be incorrect to describe these as 45 legally verified chicken-keeping conclusions.

## Regression rules

- A primary clause requires actual effective city/statute text, precise section, scope and independently reviewed recorded metadata; a mere link can never be automatically promoted.
- A `source_recorded` pending record MUST have a government reference URL, an `evidenceLevel`, an explicit unresolved `detail`, `checkedAt`, and `verifiedClaim:false`.
- Any pending city's page MUST remain `noindex,follow`, omit FAQ rich results, and be absent from the published sitemap; planners stay manual.
- A missing link, publisher access error, or historical amendment can be reported as source research, not current-law proof.
