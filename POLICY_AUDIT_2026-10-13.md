## Maintenance protocol

1. Check the **currently codified** city ordinance/municipal code and any newly enacted but uncodified amendments. Do not use draft legislation as operative law.
2. Reconcile state preemption (especially Arizona 2024 backyard-fowl legislation) before publishing local limits or setback numbers.
3. Check lot-size, zoning, written-consent and neighbor-building conditions; use `verified_limited_scope` if the source proves only some relevant facts.
4. Preserve full official URL and specific code section / effective date when available; obtain city-planning confirmation for inaccessible code.
5. Update `site/data/cities.json`, then regenerate and test; do not manually mark `needs_review` entries as verified simply to reach 100 indexed pages.

Run checks:

```bash
node scripts/generate-policy-data.cjs --check
node scripts/generate-coverage-pages.cjs --check
node scripts/qa-coopcheck.cjs
node scripts/qa-coop-payment.cjs
```
